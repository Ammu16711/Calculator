# Tip Calculator App

## Introduction
The Tip Calculator is a simple Flutter
application developed using Dart.

## Objective
To calculate the tip amount, total bill
and amount per person.

## Technologies Used
- Flutter
- Dart
- DartPad

## Features
1. Enter bill amount.
2. Select tip percentage.
3. Add or remove people.
4. Calculate tip amount.
5. Calculate total bill.
6. Display amount per person.

## Sample Output
Bill Amount: 1000
Tip Percentage: 10%
Number of People: 4
Tip Amount: 100
Total Bill: 1100
Amount Per Person: 275

## Conclusion
This project helps us understand Flutter
widgets, Dart programming and setState().
